Overview

What is Kivo?

In plain words: one app for private chats (like WhatsApp) and communities (like Discord), with unusually deep theming. Built by one student (Ayush) to learn full-stack properly — but real people can use it daily. Live at kivo.usersynax.dev, open source user-synax/Kivo.
📱 DMs & Groups

Private 1:1 DMs (unique per pair via $all) + small groups (you + ≥2 friends, admins, system chips, last-admin protection).

🛰️ Spaces & Channels

Discord-like servers: text + announcement channels, roles owner → admin → moderator → member, Discover + 7-day rotating invites.

🎨 Customization

10 presets + personal studio + per-Space palettes + per-chat look + wallpapers + bubbles + profile effects. Beyond light/dark.

Principles

Fast & realtime · Simple despite rich · Personal & customizable · Clean responsive UI (bottom tabs on phones, icon rail on desktop) · Privacy + authorization foundational — never trust the client · One identity across DMs/Groups/Spaces · No premature microservices.

📱 Everyday user manual

In plain words: if you only read one section, read this. Everything below is clickable in the real app — no technical knowledge needed.

1 · Create account & log in (2 minutes)

  1. Open the site → Sign up. Enter display name, username (3–30, letters/numbers/_), email, password (≥8). You land in /app instantly — no OTP, no waiting.
  2. Or tap Continue with Google / GitHub — a new account is made for you (email pre-verified, provider photo as avatar). Same email as an existing account? They're auto-linked, nothing lost.
  3. Log in later with email or username + password, or the provider button. OAuth-only accounts (no password) tell you to use the provider button instead.
  4. Forgot password? Forgot password → email → 1h link → new password. All devices are signed out — log in again.

2 · Layout: desktop vs phone

🖥️ Desktop / tablet

Far-left icon rail: Chats · Nearby · Status · Groups · Spaces · Emoji Factory · Settings, avatar at bottom. Header has bell 🔔, search Ctrl+K, New menu. Center = chat; right = profile/group/Space panel on wide screens. Unread dots sit on rail icons.

📱 Phone

Bottom tabs: Chats · Status · Groups · Spaces · Menu. Menu holds Nearby, Discover, profile, Appearance (full-screen themes), Settings — each a pushed screen with Back. Edge-swipe goes back; notches respected.

3 · Friends, Find & Nearby

  1. New → Friends → Find: search username/email/name (300ms debounce). Results are square cards — tap View profile or Send Request.
  2. Sending? Choose with welcome message (≤280 chars, shown before accept — be kind, only they see it) or without. Can't friend yourself, blocked users, or duplicates.
  3. Requests tab: accept/decline; welcome shows as a Quote bubble. Sender gets a notification (80-char snippet).
  4. Friends tab → Message opens/creates the DM. Unfriend from any profile — removes both sides live; history stays until you Remove-from-list.
  5. Nearby (rail / Menu → Nearby users, full-screen): first open shows a consent sheet. Tap Share location (one-shot, not tracking) → see people by fuzzed distance only (250 m / 1.2 km — never exact). Radius chips 1/2/5/10 km. Off in Settings → Privacy → Nearby discovery (hides you + clears location).

5 · Groups & Spaces

👥 Groups (private circles)
  1. Groups → New group → name (≤50) + optional photo + ≥2 friends.
  2. You become first admin. Settings: rename/photo, add/remove, promote/demote. Last admin can't be removed.
  3. Joins/leaves show as centered chips, live for all.
🏠 Spaces (communities)
  1. Spaces → New → name/desc/category/banner/avatar → auto #general. You own it.
  2. Text channels = all post; announcement = admins only. Admin+ manages channels (last protected).
  3. Roles owner→admin→moderator→member. Owner-only: promote admin, delete Space.
  4. Discover → search/category → Join (public). Private = hidden, invite link/code only (7-day rotating, Space settings → Privacy & invites; /app?join=CODE deep-link).

6 · Make it yours + stay notified + Plus

  1. Appearance (full-screen): 10 themes switch live, no reload. Studio recolors accent + canvas tone → Save to my account (follows you). Chat look: wallpaper (Plain/Dots/Grid/Lines/Bubbles/Wash) + bubbles (Rounded/Pill/Squared/Outlined-mine). Per-chat palette icon overrides; Spaces can set their own look for members.
  2. Profile (rail avatar / Menu): name, handle, bio 280, status 60 + emoji chip (32 + 6 vibes), photo 4MB, 10 frames, banner (curated GIFs; Plus: your own ≤8MB), effects (Plus: glow/gradient-name/aura), country flag, GitHub graph, X/Instagram/YouTube/website chips, pronouns, status auto-clear, privacy toggles.
  3. Public page /u/you: share + QR. Visitors Wave 👋 (20s cooldown → notification deep-linking to them), add/message/block.
  4. Bell 🔔: DMs/groups/Spaces/mentions/requests/waves. Click → jump + mark read. Settings → Notification preferences per category (Space msgs OFF default; mentions break through). Sounds per category + master + preview (synthesized, no downloads). First bell-open asks push permission → offline pings even when closed. Quiet automatically when you're already viewing that DM.
  5. Install (PWA): Chrome/Edge address-bar install icon · Android Add to Home Screen · iPhone Share → Add to Home Screen. Recent chats paint instantly offline; offline texts queue and auto-send on reconnect.
  6. Plus ₹49/mo: /plus → pay published UPI ID → paste 12-digit UTR → approved within 24h → 30 days Plus (custom banner/effects/emoji, bigger limits). Status cards show pending/rejected/expired.
  7. Safety: Block from any DM/profile (removes friendship, hides chat, server-enforced). Manage in Settings → Blocked users (one-tap unblock). Remove-from-list deletes a DM/group for everyone (confirm twice — permanent). Admins can ban rogue accounts.
Flows

🗺️ Five journeys, end to end

① Signup → first DM (3 min)
  1. Signup → land /app.
  2. New → Friends → Find → search friend → Send Request (+ "hey, it's me!").
  3. They Accept → Friends → Message → type → Enter → ✓✓ blue. Right-click → Pin "coffee Saturday".
② Squad group
  1. Groups → New group "Project X" + photo + 2 friends → Create.
  2. Chat, @mention the lead (overrides mute), start a Thread on the plan message.
  3. Promote a co-admin; leave anytime (last admin protected).
③ Space community
  1. Spaces → New "Design Club" (category Design) → #general ready.
  2. Space settings → add #inspiration (text) + #news (announcement).
  3. Private? Privacy & invites → New link (7d) → share /app?join=CODE. Public? It appears in Discover.
  4. Give it a look (accent + wallpaper) — members see it in channels.
④ Plus UPI
  1. /plus → pay ₹49 to shown UPI ID in any UPI app → copy 12-digit UTR.
  2. Paste UTR → claim filed (pending card). Admin approves ≤24h → 30d Plus.
  3. Upload custom banner + glow effect + personal emoji :mylogo:.
⑤ Offline hero
  1. Enter a tunnel, keep typing → messages queue in outbox (banner "You are offline").
  2. Reload — drafts + queue survive (IndexedDB).
  3. Back online → queue flushes in order + gap-fill pulls what you missed. Nothing lost.
Core mental model

The journey of a message

In plain words: your words paint instantly, get verified by the server, then everyone is told at once. If anyone was offline, the system catches them up quietly.
Client → POST /api/v1/conversations/:id/messages → Auth(JWT) → Zod validate → Authorize membership → Rate-limit 40/min → MongoDB write → Socket.IO emit message:new → recipients → delivered/read acks → Notifications (bulk insertMany + fire-and-forget push) → Offline? outbox flush Mantra: instant paint → verified truth → instant delivery → quiet catch-up.

Architecture

Architecture, API & file tour

Browser ──HTTPS──▶ Next.js ──REST──▶ Express ──▶ MongoDB │ │ └────── Socket.IO (realtime) ◄───────┘ Appwrite (files) · VAPID (push) · LiveKit (media) REST saves/fetches. Socket announces. DB write FIRST, emit SECOND.

Networking rule (interview favorite)

REST uses relative /api/… → Next.js rewrites (next.config.mjs) to BACKEND_URL (default http://localhost:4000), staying same-origin so sameSite=strict httpOnly cookies flow without CORS. Socket.IO dials NEXT_PUBLIC_API_URL directly — rewrites can't proxy WebSocket upgrades. Config: frontend/lib/api.js (fetch + auto-refresh) · components/socket-provider.jsx.

Realtime

Socket.IO: rooms, presence, receipts

In plain words: one always-open wire per device. The server puts you in a "room" per chat/Space and shouts into the right room when something happens. Online dots only go to people who share a chat with you — not the whole internet.
🔌 Connection

JWT handshake (same secret as HTTP); banned rejected. Auto-join conversation:{id} + space:{id}. socket/io.js helper emitToConversation. File socket/index.js.

🟢 Presence (scoped)

Map<user,Set<socket>> single-instance. Peers = union of conversations+spaces (getRelevantPeerIds). 12s grace (pendingOffline) stops flicker. presence:snapshot fixes late joiners. Offline = lastActiveAt → "active X ago" (lib/last-active.js).

⌨️ Typing

typing:start/stop {conversationId} → room excl. sender. No DB write. Client: chat-panel.jsx.

✅ Receipts

message:delivered {messageId} → $addToSet → delivery-updated. Read = anchor {userId,upToMessageId,upToCreatedAt,readAt} → client groups Read/Delivered. Tap ticks → portaled Seen-by (message-bubble.jsx).

🔁 Gap-fill

Reconnect → refetch list (single agg) + after=newestId → merge into cache.js. No full download.

📞 Ring only (media = LiveKit)

call:ring/accept/decline/end → accepted/declined/ended/missed/failed. 30s activeRings → missed chip+bell (calls.service recordMissedCall). 3s spam guard. Blocked → CALL_BLOCKED.

Auth & security

Identity, trust, and guards

In plain words: short-lived tickets prove who you are; a hidden cookie keeps you logged in; the server can revoke either instantly (logout everywhere, password reset, ban). Every input is validated; every action checks permission.
⚡ Instant signup

name + username ^[a-zA-Z0-9_]+$ 3–30 + email + password ≥8 → bcrypt12 → user + session → access + httpOnly cookie → /app. Duplicate → CONFLICT. GuestGate/AuthGate (components/auth-guard.jsx).

🎫 Sessions that revoke

Access 15m Bearer + refresh strict-cookie backed by Session TTL. POST /refresh-token mints access, no rotation (race-safe). Single-flight + 60s early refresh (lib/api.js). Logout one / logout-all / reset-all / ban-all = delete docs.

📧 Verify + reset

Verify 24h SHA-256 link + resend 1/min (API-only today). Forgot 5/5min always-success (no enumeration) 1h; reset 10/5min + kill all. Gmail SMTP fire-and-forget (lib/email.js, FRONTEND_URL links).

🔢 2FA TOTP

Optional. In-repo lib/totp.js RFC6238 SHA-1/30s constant-time; QR (qrcode); pending secret; bcrypt-hashed single-use backups; 5m ticket → session; password to disable (OAuth-only exempt). UI: dashboard/two-factor-section.jsx.

🔑 Google + GitHub

GET /oauth/providers gates buttons. Start 302 signed-state → callback creates (pre-verified, derived username, provider avatar if unset) or auto-links by email. link-url embeds userId. PROVIDER_ALREADY_LINKED; sparse-unique; OAuth-only null password → OAUTH_ONLY_ACCOUNT. Both linked → native verified. UI: auth/OAuthButtons.jsx, oauth/callback/page.jsx.

🛡️ Never trust client

Zod all inputs. Membership / sender-only / rank (owner>admin>moderator>member) / owner-only promote+delete / last-owner+admin guards. Helmet, CORS allowlist, body limits, trust proxy, allow-list uploads + old-file delete, no prod leaks.

Performance

What keeps it fast (and what to measure)

Single-agg unread

unreadCountsByConversation() kills N+1 countDocuments. Measure: inbox latency vs conv count.

Bulk + async fan-out

One insertMany + batch prefs; sender never waits on VAPID. Measure: POST p95 vs recipients.

Memoized rows

React.memo MessageRows + stable ctx + O(1) replies. Typing/scroll/presence skip re-renders.

Cheap media UI

useMemo 32-bar waveform (no canvas/fetch), tabular-nums timer (no CLS), shared audio; in-chat highlight client-only.

Pagination + indexes

Cursor + around + after; index per read pattern + text index. Don't optimize blind — measure first.

content-visibility

Off-screen rows skip layout/paint. No virtualization code to maintain.

Glossary

Terms, plainly

Realtime

Arrives the moment it's sent — no refresh.

WebSocket / Socket.IO

Two-way wire that stays open browser↔server.

Room

Broadcast group — e.g. one per chat. Only members hear it.

JWT (15m)

Signed tamper-proof ticket proving who you are.

httpOnly cookie

Cookie JavaScript can't read — holds your login session.

Optimistic UI

Show it instantly, confirm when server answers.

PWA / Service worker

Installable website / background script for offline + push.

IndexedDB / Outbox

Browser database for cache / queue of offline sends.

VAPID / Web Push

Standard letting servers ping browsers when closed.

Zod

Schema checker rejecting bad input on the server.

SSRF

Tricking a server into fetching internal URLs — Kivo guards previews against it.

SFU (LiveKit)

Media server forwarding audio/video without mixing — scales calls.

TOTP / 2FA

Time-based authenticator codes — second login step.

UTR

12-digit UPI payment reference you paste to claim Plus.

2dsphere / $geoNear

Mongo geo-index + nearest-first query powering Nearby.

# Spaces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Spaces — a workspace container for channels with role-based access, own name/avatar/banner/description, invite links, and categories — reusing the existing Group/DM/Message infrastructure.

**Architecture:** Create a new `Space` Mongoose model with embedded `channels[]` and `members[]` (role enum). Each channel maps to a `Conversation` document of new type `space_channel` keyed by `spaceId + channelId` so existing `Message` + socket flows are reused. Backend adds `modules/spaces` (validation/service/controller/routes) following the `conversations` pattern; frontend adds `lib/spaces` + `components/spaces/*` and integrates into `dashboard-shell`/`sidebar`/`chat-panel` without breaking DMs/Groups.

**Tech Stack:** Node 20 / Express, Mongoose 8, Zod, Socket.IO 4, Appwrite Storage (avatar upload), Next.js 16 (App Router), Tailwind 4, lucide-react, motion.

import mongoose from "mongoose";
const ROLES = ["owner","admin","moderator","member"];
const CHANNEL_TYPES = ["text","announcement"];

  inviteExpiresAt: { type:Date, default:null },
  channels: { type:[channelSchema], default:[] },
  isPrivate: { type:Boolean, default:false },
}, {timestamps:true});
spaceSchema.index({ "members.userId":1 });

export const createSpaceSchema = z.object({

  description: z.string().trim().max(500).optional().or(z.literal("")),
  category: z.enum(SPACE_CATEGORIES).optional(),
  banner: z.string().trim().max(2000).nullable().optional().or(z.literal("")),
  isPrivate: z.coerce.boolean().optional(),
});
export const updateSpaceSchema = z.object({
  name: z.string().trim().min(2).max(50).optional(),
  description: z.string().trim().max(500).optional(),
  category: z.enum(SPACE_CATEGORIES).optional(),
  banner: z.string().trim().max(2000).nullable().optional().or(z.literal("")),
  isPrivate: z.coerce.boolean().optional(),
});
export const memberRoleSchema = z.object({ role: z.enum(["admin","moderator","member"]) });
export const createChannelSchema = z.object({
  name: z.string().trim().min(2).max(30).regex(/^[a-z0-9-]+$/,"lowercase, numbers, hyphens"),
  description: z.string().trim().max(280).optional().or(z.literal("")),
  type: z.enum(["text","announcement"]).optional(),
});
export const inviteSchema = z.object({ expiresInHours: z.coerce.number().int().min(1).max(720).optional() });
export function parseBody(schema, body){ const r=schema.safeParse(body); if(!r.success){ const e=new Error(r.error.issues[0]?.message||"Validation failed"); e.statusCode=400; e.code="VALIDATION_ERROR"; throw e; } return r.data; }
